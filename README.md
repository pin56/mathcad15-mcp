# mathcad15-mcp

MCP-сервер (stdio) для **PTC Mathcad 15** (.xmcd): агент пишет листы на компактном DSL,
правит готовые, подставляет исходные данные, пересчитывает, читает результаты и ошибки,
экспортирует. Mathcad Prime не поддерживается — для него есть другие серверы.

Проверено с Claude Code и LM Studio (локальная Qwen). Схемы шести инструментов занимают
≈3.5 тыс. символов, ответы — короткий текст, не JSON.

## Требования

- Windows, установленный Mathcad 15 (COM `Mathcad.Application`).
- Python ≥ 3.10 (Mathcad 32-битный, но COM LocalServer работает и из 64-битного Python).
- Для PDF — Microsoft Word (PDF делается так: Mathcad → RTF → Word).

Без Mathcad сервер тоже стартует: `mc_write` пишет файл без пересчёта, `mc_read`
показывает результаты, сохранённые в файле (с пометкой).

## Установка

```bash
cd Z:/my_files/mathcad15-mcp
```

```bash
python -m venv .venv
```

```bash
.venv/Scripts/python.exe -m pip install -e .
```

Запуск сервера: `.venv\Scripts\python.exe -m mathcad15_mcp` (или скрипт `mathcad15-mcp`).

## Регистрация

Claude Code (`~/.claude.json`, раздел `mcpServers`):

```json
"mathcad": {
  "type": "stdio",
  "command": "Z:\\my_files\\mathcad15-mcp\\.venv\\Scripts\\python.exe",
  "args": ["-m", "mathcad15_mcp"],
  "env": {}
}
```

LM Studio (`~/.lmstudio/mcp.json`):

```json
{ "mcpServers": { "mathcad": {
  "command": "Z:\\my_files\\mathcad15-mcp\\.venv\\Scripts\\python.exe",
  "args": ["-m", "mathcad15_mcp"]
} } }
```

После регистрации клиент нужно перезапустить. Переменная `MATHCAD_TIMEOUT` (секунды,
по умолчанию 120) ограничивает одну операцию Mathcad.

## Инструменты

| Инструмент | Аргументы | Что делает |
|---|---|---|
| `mc_help` | `topic?` | Справка по DSL: обзор; темы syntax, units, program, solve, plot, symbolic, examples |
| `mc_read` | `path`, `regions?` ("3-8"), `errors_only?` | Открыть (.xmcd, .mcd), пересчитать, показать регионы `[n]` как DSL + результаты + ошибки |
| `mc_write` | `path`, `text`, `overwrite?` | Новый лист из DSL; ответ как у `mc_read` |
| `mc_edit` | `path`, `start`, `end`, `text?` | Заменить регионы `[start..end]`; `end = start-1` — вставка, пустой `text` — удаление |
| `mc_calc` | `path`, `set?` {имя: выражение}, `get?` [имена], `save?` | Подставить данные, пересчитать, вернуть значения и ошибки; без `save` файл не меняется |
| `mc_export` | `path`, `out?`, `format?` | pdf, rtf, html, xmcd, xmcdz |

Пути — абсолютные. Агенту стоит начинать с `mc_help()`.

## Пример

`mc_write("Z:\\calc\\балка.xmcd", text)`:

```
# Балка
L.b := 6 m
q := 12 kN/m
M := q*L.b^2/8
M = ? kN*m
σ := M/W.x
σ = ? MPa
```

Ответ:

```
балка.xmcd — 7 регионов, 2 ошибки
[1] # Балка
[2] L.b := 6 m
[3] q := 12 kN/m
[4] M := q*L.b^2/8
[5] M = ? kN*m  → 54 kN·m
[6] σ := M/W.x  ✗ W.x: Эта переменная не определена
[7] σ = ? MPa  ✗ Эта переменная не определена
```

Дальше: `mc_edit(path, 6, 5, "W.x := 400 cm^3")` вставит определение перед `[6]`,
`mc_calc(path, set={"L.b": "8 m"}, get=["M = ? kN*m", "σ"])` вернёт `96 kN·m` и `2.4e8 Pa`,
не трогая файл.

Обозначения: `→` результат, `✗` ошибка, `⚠` предупреждение (например, имя переопределяет
встроенную единицу). То, что DSL не выражает, показывается как `raw: <xml…>`; так же можно
и писать.

## Особенности и ограничения

- Mathcad запускается скрыто и только из COM; клавиши не нажимаются, фокус не крадётся.
  Свой экземпляр сервер закрывает при выходе и убивает при таймауте. Если COM отдал уже
  запущенный Mathcad пользователя, сервер работает через него, но не закрывает и не убивает:
  такой экземпляр может показывать окна, а таймаут превращается в обычную ошибку.
- Апостроф — часть имени (`y'`), транспонирование — `transpose(A)`.
- `M = ?` без единицы показывает SI (`2.4e8 Pa`); нужна своя — `M = ? MPa`.
- Единицы `kJ` в Mathcad 15 нет: `1000 J`. `g` — ускорение свободного падения, грамм — `gm`.
- Имена вроде `L`, `A`, `S`, `F`, `s`, `g` совпадают со встроенными единицами и функциями
  и дают `⚠`; лучше `L.b`, `Ka`, `S.p`.
- У матрицы с единицей нужен `*`: `[1; 2]*m`. `limit` работает только символьно (`-> ?`).
- После сохранения Mathcad может зафиксировать один из пределов графика: такой график
  читается как `ylim=-1..?` (`?` — автопредел).
- PDF — через Word из RTF: вёрстка Word, формулы иногда искажаются. Для точной копии
  листа лучше html или xmcd.
- `mc_edit` и `mc_calc save` работают только с .xmcd; .mcd сначала `mc_export(path, out="….xmcd")`.

## Тесты

```bash
.venv/Scripts/python.exe -m pytest -q tests/
```

Тесты с маркером `mathcad` требуют Mathcad 15 (`MC15_SKIP_COM=1` пропускает их).
`tests/test_corpus.py` прогоняет ≈20.5 тыс. формул из примеров Mathcad 15 через
XML → DSL → XML: 99.5% без `raw:`, 0 расхождений.
