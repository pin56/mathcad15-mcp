# Mathcad 15 MCP Implementation Plan

> **For agentic workers:** исполняется нативно в той же сессии (пользователь: «Жду готовую работу»).
> Шаги — чекбоксы `- [ ]`.

**Goal:** stdio MCP-сервер с 6 инструментами для генерации и обработки листов Mathcad 15 через DSL и COM.

**Architecture:** DSL → AST → XML math30 / двоичный блоб графика → .xmcd; пересчёт и чтение
результатов в отдельном скрытом экземпляре Mathcad через COM в STA-потоке; ответы — компактный текст.

**Tech Stack:** Python 3.12, mcp 2.3 (`mcp.server.mcpserver.MCPServer`), pywin32, pytest, uv.

**Spec:** `docs/superpowers/specs/2026-10-12-mathcad15-mcp-design.md`

## Global Constraints

- Только свой экземпляр Mathcad (`DispatchEx`), `Quit(2)`/kill только своего PID.
- Никаких SendKeys/фокуса.
- 6 инструментов: `mc_read`, `mc_write`, `mc_edit`, `mc_calc`, `mc_export`, `mc_help`.
- Ответы текстом, `[n]` 1-based, `→` результат, `✗` ошибка.
- Пространства имён xmcd: worksheet30, math30, units10; шаблон `template\RU\Normal.xmct`.

## Review Focus

1. Кириллица/греческие имена (σ, α, Δp) — в XML, в блобе графика (UTF-16) и в выводе (stdout UTF-8).
2. Неподдерживаемые конструкции в чужих листах — `mc_read` не падает, показывает `raw:`.
3. Бесконечный цикл в программе листа — таймаут, kill своего PID, следующий вызов работает.
4. Ошибка синтаксиса DSL — номер строки и текст, файл не тронут.
5. Путь с пробелами/кириллицей и относительный путь — нормализуется в абсолютный.

**Files:** `src/mathcad15_mcp/expr.py`, `src/mathcad15_mcp/mathml.py`, `tests/test_expr.py`, `tests/test_mathml.py`

**Interfaces — Produces:**
- `expr.Node` (dataclass `kind: str, args: list, attrs: dict`), `expr.parse_expr(text) -> Node`, `expr.ParseError(msg, pos)`.
- `mathml.to_xml(node) -> str` (фрагмент `ml:`), `mathml.from_xml(elem) -> Node`, `mathml.to_dsl(node) -> str`.

- [ ] Тесты: `6 m` → mult(real 6, id m); `-x^2` → neg(pow); `A^<j>`, `M.max`, `v[i, j]`, `A'`, `n!`;
      `[1, 2; 3, 4]` (по столбцам); `3i`; `"s"`; `integral(x^2, x, 0, 1)`; `Find(x, y)`; `sqrt`, `nthroot`.
- [ ] Реализация Pratt-парсера и компилятора/декомпилятора; тесты зелёные.
- [ ] Коммит.
